id: US-0018
title: Über neue Versionen informiert werden
epic: E-SKILLS
requirements: []
status: open
---

Als **Nutzer von docspine** möchte ich bei der Arbeit erfahren, dass es eine neuere
Version gibt, mit einer kurzen Release-Note, und sie auf Wunsch direkt einspielen
können, damit mein Projekt nicht unbemerkt auf einem alten Stand bleibt.

**Hintergrund.** Heute erfährt man von einer neuen Version nur, wenn man selbst
nachsieht. Bausteine dafür gibt es schon: Die installierte Version steht im Kopf von
`.docspine/STANDARD.md`, die Änderungen je Version im `CHANGELOG.md`, und eine neue
Version hat einen Tag. Offen ist, wann und wie geprüft wird: beim Aufruf eines Skills,
beim Start einer Sitzung (werkzeugspezifisch, z. B. über einen Hook in Claude Code)
oder über einen Befehl des Prüfwerkzeugs. Die Prüfung braucht Netzzugriff und darf eine
Arbeit ohne Netz nicht stören.
