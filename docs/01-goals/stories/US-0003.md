Als **Projektverantwortlicher** möchte ich das Frontmatter aller Artefakte als JSON Schema haben, damit Editoren und Werkzeuge es beim Schreiben prüfen.

**Hintergrund.** ADR-0009. Entfällt mit ADR-0023: Die Prüfung genügt.

**Erst bei Bedarf umsetzen.** Geprüft wird das Frontmatter schon vom Prüfwerkzeug
(Fehlerklasse 1). Ein JSON Schema hilft zusätzlich nur Editoren, die Fehler schon beim
Tippen anzeigen. Gebaut wird es, sobald jemand mit einem solchen Editor danach fragt.
