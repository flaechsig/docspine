id: ADR-0023
title: Kein JSON Schema für das Frontmatter
status: accepted
date: 2026-10-06
---

## Kontext

ADR-0009 legt unter anderem fest, dass das Frontmatter-Schema zusätzlich als JSON Schema
veröffentlicht wird, damit Editoren und andere Werkzeuge es prüfen können. US-0003 ist
die Story dazu; sie war von Anfang an mit „erst bei Bedarf umsetzen“ markiert.

Das Prüfwerkzeug prüft das Frontmatter bereits (Fehler 1). Die meisten Artefakte
schreiben Skills, die danach die Prüfung laufen lassen. Ein JSON Schema hilft nur beim
Schreiben von Hand in einem Editor, der Fehler schon beim Tippen anzeigt. Bisher hat
niemand danach gefragt.

## Entscheidung

docspine veröffentlicht kein JSON Schema für das Frontmatter. Das Schema hat eine
Quelle: das Prüfwerkzeug. Dieser Punkt von ADR-0009 entfällt; die übrigen Festlegungen
von ADR-0009 gelten unverändert.

Verworfen:
- **JSON Schema veröffentlichen:** eine zweite Beschreibung desselben Schemas neben dem
  Prüfwerkzeug, die gepflegt werden muss und sonst auseinanderläuft (Grundsatz 1, eine
  Quelle je Aussage).
- **Schema aus dem Prüfwerkzeug erzeugen:** vermeidet das Auseinanderlaufen, ist aber
  Aufwand für einen Nutzen, den bisher niemand braucht.

## Konsequenzen

- Fehler im Frontmatter zeigt erst die Prüfung, nicht schon der Editor.
- US-0003 wird nicht gebaut. Fragt jemand mit einem solchen Editor danach, entsteht eine
  neue Story, und diese Entscheidung wird abgelöst.
